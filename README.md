# Fractal Hash

This program generates a random [Neuwtons Fractal](https://en.wikipedia.org/wiki/Newton_fractal). At attempt has been made to make each fractal feel unique.

# Goals

- Each fractal should be "interesting", have a balance between high frequency and low frequency components and have some consideration for framing and balance
- Each fractal should feel unique, not just be technically a slightly different shape but actually have a distinct aesthetic.

A hypothetical goal is this techniquecan be used for actual image hashing purposes, eg. verifying SSH key signatures. Though note the current RNG is not cryptographically secure.

# Techniques

- Random equations: The code generates a random combination of trignometric and polynominal functions which should create a quite high degree of variability.
- Random coloring modes, based on iterations, closest root, angle, final position and combinations of these.
- Differently shaped "catchment areas" can create pointy or otherwise intrestingly shaped edges, for color modes where edges are visible.
- Different color schemes, which just change the apperance.

I want to add more equations and color modes and also see if I can do more to reduce the chance of generating a "boring" fractal.

# What is a "Boring" Fractal?

Since we want to avoid "Boring" fractals, lets define them:

- An entirely empty fractal is boring, which generally results from there not being any points with deriviative 0 in the visible area
- A fractal that is too dense is also boring, as it is hard to make out a structure

A fractal can also be "Ugly". A fractal can be ugly if:

- It has areas of high density noise causing aliasing
- Ugly hard lines or jagged edges, while tastefull hard lines are fine. (Not sure how to define the difference but you know it when you see it)
- Clashing colors or patterns, even a good color scheme can cause clashing colors if the color mode puts bad areas close to each other.
